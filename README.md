# そのガード、見切った。 — ３択じゃんけんボクシング

「速いジャブ・ボディー・顔ガード」で、じゃんけんと同じ３すくみの勝負をするゲームです。

**相手の技はMathオブジェクトの `Math.random()` と `Math.floor()` で抽選し、if文で選びます。勝敗も `if / else if / else` で判定します。**

## ゲームのルール

| 自分 ＼ 相手 | 速いジャブ | ボディー | 顔ガード |
| --- | --- | --- | --- |
| 速いジャブ | アイコ | 勝ち | 負け |
| ボディー | 負け | アイコ | 勝ち |
| 顔ガード | 勝ち | 負け | アイコ |

- **速いジャブ → ボディーに勝つ**：このゲームでは、ボディーより先にジャブが当たる設定です。
- **ボディー → 顔ガードに勝つ**：顔を守っていても、お腹には当たります。
- **顔ガード → 速いジャブに勝つ**：顔へのジャブを防いで反撃します。
- 同じ技はアイコ。お互いのHPは変わりません。
- お互いのHPは５。勝つと相手に１ダメージ、負けると自分に１ダメージ。HP０でKOです。

## 工夫した点、こだわった点
-ボクシングを知らない人にも伝わるように、技を３つに絞り、ボタンに相性を表示しました。
-「速いジャブはボディーに勝つ」「顔ガードはジャブに勝つ」「ボディーは顔ガードに勝つ」というルールにしました。(実際は必ずしもそうではないですが)
-3人の対戦相手を作り、Mathオブジェクトの乱数とif文で、それぞれに癖を作りました。対戦相手ごとに得意技を60％で出すように設定しました。


## リッチバージョンで付け加えた点；パンチ音
`new Audio()` で音を用意し、`volume` で音量を設定します。0なら無音、1なら最大音量です。

`play()` の中で勝ち・負けになったときに `playPunchSound()` を呼びます。その関数では `currentTime = 0` で音の最初に戻し、`play()` で再生します。後ろの `.catch()` は、再生に失敗してもゲームを続けるための処理。
